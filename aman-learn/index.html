Questions, answered

Parents ask. Students ask. We keep it clear.

Is this for complete beginners?

Yes. Most tracks start from the very beginning and use familiar, practical examples. You do not need prior computer experience.

Where does learning happen?

Classes run at the centre in Indra Park, Palam Village, with notes and practice sheets you can open at home whenever you need a reminder.

Can I ask questions outside class?

Yes. Call or message Aman when something is stuck. Getting unstuck quickly is the whole point of learning with a local teacher.

Which course should I start with?

If you are unsure, start with DCA for everyday computer confidence, or Advanced Excel if you already work with data. Tell Aman your goal and he will point you at the shortest useful path.
